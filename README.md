# Kompas 3D Print

Библиотека для КОМПАС-3D: подготовка моделей к 3D-печати и несколько генераторов
геометрии. Написана на C++ (U++), работает с КОМПАСом через [KompasAPI](KompasAPI/README.md).

## Возможности

**Экспорт и печать**

- Экспорт активной модели в STL, STEP (в том числе AP203/AP214/AP242), IGES, VRML,
  ACIS, Parasolid, JT.
- Отправка модели в слайсер одной командой: экспорт во временный файл и запуск
  слайсера (UltiMaker Cura находится автоматически, путь можно задать вручную).
- Настройки экспорта: формат, единицы, текстовый или двоичный STL, тела и/или
  поверхности, точность триангуляции (линейная, угловая, по длине ребра).

**Генераторы**

- **Шестерня** — по модулю, числу зубьев и толщине.
- **Рейка** — по модулю, длине, толщине и глубине.
- **Реальные резьбы** — заменяет условные изображения резьбы в модели настоящей
  винтовой канавкой, чтобы резьба напечаталась. Учитывает зазор печати.
- **Стандартные изделия** — вставка модели из папки «Стандартные изделия» с выбором
  исполнения и сопряжениями (в работе).

Созданное генератором помещается в макрообъект вместе с параметрами, поэтому
результат можно выделить в дереве и отредактировать — панель откроется с прежними
значениями.

## Установка

Собрать конфигурацию `Kompas3DPrint.rtw` и подключить полученный файл в КОМПАС-3D:
**Настройка → Параметры → Система → Библиотеки → Подключить**. Команды появятся в меню
библиотеки.

Настройки хранятся в `Kompas3DPrint.ini` в папке конфигурации КОМПАСа.

## Сборка

Нужны [U++](https://www.ultimatepp.org/) и SDK КОМПАС-3D (пути к нему прописаны в
`KompasAPI/KompasAPI.upp`, по умолчанию `C:/KSDK24`).

Две конфигурации:

| Конфигурация | Что получается |
|---|---|
| `Kompas3DPrint.rtw` | библиотека КОМПАСа (GUI DLL) — обычный режим |
| `App` | отдельное приложение; подключается к запущенному КОМПАСу по COM, удобно для отладки |

## Структура

```
Kompas3DPrint.cpp   точка входа, диспетчер команд меню
Resources.h         идентификаторы команд
Kompas3DPrint.rc    меню библиотеки
Layouts.lay         формы диалогов
Command/            по файлу на команду: Export, Slicer, Settings,
                    Gear, Rack, Threads, StandardParts, AboutDlg
KompasAPI/          обёртка над API КОМПАСа (отдельный пакет U++)
```

Новая команда добавляется так: идентификатор в `Resources.h`, пункт в
`Kompas3DPrint.rc`, класс в `Command/`, ветка в `Kompas3D::RunCommand`.

## Ограничения

- Настройки автоэкспорта в диалоге есть, но сам автоэкспорт при сохранении документа
  ещё не подключён.
- Только Windows: реализация под Linux (`KompasAPI/Ksapi/`) не написана.
- Стандартные изделия - в работе
